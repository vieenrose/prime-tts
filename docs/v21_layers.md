## Packed layouts (the contract the C runtime codes against)

| container name | content | layout |
|---|---|---|
| `<grp>.<mod>.wp` | conv weight `[Cout,Cin,K]` | `[Cout4/4][K][Cin][4]`, Cout zero-padded to `Cout4=ceil(Cout/4)*4` |
| `<grp>.<mod>.wp#h` | same, fp16 payload | 39 tensors, all decoder convs |
| `<grp>.<mod>.b` | conv bias | `[Cout4]` fp32, added once per output channel |
| convT weight | ONNX `[Cin,Cout,K]`, stride `s`, pad `p` | `s` phases x `ntap=ceil(K/s)` taps, packed with `pack_conv` → `[s*C4/4][ntap][Cin][4]`; row `r*C4+c` = phase `r`, channel `c`; tap `j` = ONNX kernel tap `k = r + j*s` |
| `<grp>.<mod>.emb` | embedding table | `[rows,cols]` fp32 (4 tables) |
| `<grp>.<mod>.pad.relpos`, `pad_5.relpos` | attention rel-pos tables | `[1,9,96]` fp32 (12) — the **unpadded** table, pads are runtime data |
| `<grp>.<mod>.g`, `.beta` | LayerNorm | `[C]` fp32 (14 pairs) |
| `const.<nodeidx>` | float Constant-node tensors | 34 tensors (the iSTFT basis, the 63-tap lowpass, scalars) |
| `model.meta`, `dec.geom`, `dtype.table` | meta | geometry + one itemsize per record, record order |

ConvTranspose evaluation (gate (a) proves it against an ONNX reference, gate (d) proves the bytes):

```
P_r[q] = sum_{j=0..ntap-1} W[r*C4:(r+1)*C4, :, j] @ x[q-j]  + bias      # tap j is a j-step delay
out[q*s + r - p] = P_r[q]                                                # the ONNX index relation
q runs 0 .. Tin + ntap - 2                                               # the tail flush: ntap-1 zero steps
Tout = (Tin-1)*s - 2*p + K
```

The **tail flush is not optional**: with `K > s` the last `ntap-1` delay-line steps produce the
tail outputs.  Measured: dropping it in the numpy oracle collapses the waveform SNDR to 0 dB.

Weight entries by op and dtype: `conv1d` 87 fp32 + 37 fp16, `conv_transpose1d` 3 fp32 + 2 fp16,

cos-sin basis) — no weight entries; the runtime must run them as real GEMMs.

## Things the runtime must not treat as constants

* **12 rel-pos Pads**: every one of v2.1's 51 `Pad` nodes has graph-computed pads (measured at
  T=81: `[0,76,0,0,76,0]` → table `(1,9,96)` → `(1,161,96)`).  The container holds the unpadded
  table; the runtime pads to the attention width.  `params.pads_source` names the tensor that
  computes the pads.
* **39 plain Pads** on activations, incl. `/dec/Pad` (waveform tail, `[0,0,31,0,0,31]` at T=81) and
  `/dec/reflection_pad/Pad` (mode=reflect).
* **The noise branch**: `/RandomNormalLike` → `/Mul_5(noise, exp(logs))` → `/Mul_6(x, noise_scale)`.
  At `noise_scale=0` it is exactly zero from `/Mul_6` on.
* **ConstantOfShape** (82 nodes): the fill value is now recorded numerically per layer entry
  (`fill.value`, `fill.dtype`); the attribute tensor is not JSON-parseable.
* **Folded weights** (4): the iSTFT head's convT kernels and the 63-tap lowpass are computed by the
  graph (ScatterND/Mul chains).  Gate (e) folds them and compares against onnxruntime's own value
  from the probe dump: max|fold−ORT| = 0.00e+00 for all 4.

`k=r*s+j`, flipped `pack_conv` transpose, flipped tap-delay sign, un-flushed delay line, dropped bias.

## Goldens and probes

```
tests/gen_golden_v21.py  -> tests/golden_v21/{T20,T40,T81,T120,sid1_T29}/  (wav + inputs + 99
                             intermediates: first node output per (group, op_type))
tools/probe_shapes.py ... --case /tmp/case_T81.json --dump-dir tests/golden_v21/_probe_T81
                             -> 4071 node outputs for the T=81 golden case (248 MB, gitignored)
```

Ids come from `bench/cpu/requests.txt` (concatenated in file order, cut to T).  **The zh-TW
front-end (g2pw / g2p_en / entity normalisation) is NOT ported** — the latency/cost story is
complete, the text front-end is not, and these goldens therefore start from phoneme ids, not text.
Reference spread to expect: the un-optimised probe session reproduces the optimised waveform to
max|d| = 2.3e-05, so anything the runtime produces above ~2e-05 is the runtime's own error.
